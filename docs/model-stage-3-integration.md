## Reasoning constructed before evidence appraisal

The proposed conclusions were (1) successful adjustments provide the corresponding
functional benefit and (2) some inputs actually produce that benefit. The first
needs an explicit value criterion and a success definition; the second additionally
needs an actual joint causal improvement premise. Neither follows from a legitimate
professional aim alone. The canonical effect, mechanism, value, and definitions
were separated before checking the empirical source notes. The final entailment
check also included S-024 in both deductions to make explicit that the reorganization
is a change to which S-022's value criterion applies.

The Model retains the value of improved function in itself, even without symptom
relief or a separate health payoff. It also retains the professional-purpose and
actual-effect commitments. It revises the ambiguous use of “net-positive” to separate
the functional comparison from whether pursuing an intervention is worthwhile.

## Definitions, values, empirical commitments, and conclusions

| ID | Role in the completed account |
| --- | --- |
| S-021 | Definition of context-appropriate function and comparative improvement. Names actual internal state, environment, demands, baseline or alternative, functional scope, timescale, and consideration of relevant functional gains and losses together. Suitability is not defined as benefit. |
| S-022 | Explicit value premise: any qualifying improvement provides functional benefit within the same scope, context, and timescale. The explanation adopts the value of improvement in itself. Biology and measurement do not independently establish that value. |
| S-005 | Retained professional-purpose value: facilitating context-appropriate improvement is a legitimate chiropractic aim. This is distinct from valuing the outcome and from justifying a particular input. |
| S-023 | Definition of chiropractic input as a deliberately applied neurobiomechanical stimulus intended to influence neuromotor function. Delivery is defined independently of its effect. |
| S-024 | Definition of adjustment as input-caused neuromotor reorganization, with reorganization defined as changed organization of control or coordination. Passive displacement, measurement noise, and a different test result alone do not establish it. |
| S-025 | Definition of successful adjustment: an adjustment that improves context-appropriate function within a specified neuromotor scope, context, and timescale. It supplies no existence evidence or validated detection method. |
| S-026 | Evaluative conclusion that every successful adjustment provides benefit in that same scope. Classified as `value`, with `not-applicable` confidence; its universal quantifier concerns qualifying successes, not inputs or all adjustments. |
| S-009 | Empirical capacity for modifying some context-limiting strategies to improve function in a specified neuromotor scope and timescale. It establishes neither chiropractic responsiveness nor detectability. |
| S-011 | Actual empirical commitment that some inputs cause reorganization that itself improves context-appropriate function in a specified neuromotor scope, context, and timescale. Input causation and the overlap of reorganization with improvement remain explicit. |
| S-028 | Separate empirical commitment that perturbing established motor strategies causes some of those qualifying chiropractic effects. This retains the chiropractic instantiation and mechanism of the same improving response, not merely a general perturbation capacity. |
| S-027 | Actual functional-benefit conclusion from S-011 and the value criterion, using S-024's definition. Classified `mixed` because its empirical and evaluative components remain visible; confidence is unresolved. |
| S-012 | Additional empirical transfer claim: some input-produced neuromotor changes contribute to context-appropriate improvement beyond the initially affected neuromotor scope. Relevant gains and losses are assessed in the specified broader comparison. |
| S-013 | Retained empirical claim that nervous-system-mediated change is the principal route to broader chiropractic effects. Benefit, mediation, primacy, and particular pathways remain different questions. |

S-021 defines the descriptive comparison; S-022 values it. A clinician can make a
bounded comparison without complete knowledge or a unique optimum. Goals identify
relevant tasks and priorities alongside biological constraints, competing functions,
and practical demands. No ideal posture, universal symmetry, uniformly low tone,
globally accurate internal model, single favorable metric, universal score, or
arbitrary duration threshold is made the criterion.

A reported local benefit must identify its limits and disclose known losses elsewhere.
Relevant losses within the specified functions enter the improvement judgment itself.
Costs, risks, burdens, alternatives, other consequences, and uncertainty additionally
enter the intervention decision. Thus neither deduction concludes that an intervention
is worthwhile when all relevant considerations are included.

## Existing propositions retained and revised

Only four existing canonical sentences change. Their IDs remain continuous:

| ID | Previous proposition and substantive revision |
| --- | --- |
| S-005 | “Facilitating net-positive improvement in human function is a legitimate aim of chiropractic care.” Now names context-appropriate improvement as the aim. The professional-purpose commitment survives; the benefit criterion formerly carried only in its explanation is separately adopted in S-022. Worthwhile pursuit after costs and risks remains a practical condition, not part of the definition of every functional gain. |
| S-009 | “Some motor strategies that limit functional options in a given context can be modified to improve function overall.” Retains `some` and the capacity `can`, replacing unspecified “overall” with context-appropriate improvement within a specified neuromotor scope and timescale. It no longer invites a whole-person or intervention-worth inference from a local change. |
| S-011 | “Some chiropractic inputs produce beneficial changes in neuromotor function by perturbing established motor strategies.” Retains actual occurrence and joint causation, expresses the outcome as qualifying reorganization and improvement, and moves the value attribution to S-022/ARG-007/S-027. Its perturbation mechanism survives in S-028 as the mechanism of some of the same improving responses. S-011 alone is less mechanistically restrictive; the complete Model retains the stronger mechanism commitment separately. |
| S-012 | “Some chiropractic-produced changes in neuromotor function contribute to broader net-positive changes in human function.” Retains `some`, actual contribution, and broader transfer. Now asserts context-appropriate improvement beyond the initially affected neuromotor scope; S-021 defines the broader comparison and S-022 supplies its value. It does not assert that every domain improves or that the intervention is worth all its costs. |

These changes explicitly disambiguate and bound the prior “overall”/“net-positive”
claims. They are not assertions of equivalence to every possible reading of the old
wording: any reading that also asserted whole-person improvement or a favorable
decision about all intervention costs is not carried by S-009, S-011, or S-012.
Relevant functional losses remain part of judging improvement, and the broader
decision responsibilities remain in S-005 and S-014–S-016. No confidence was promoted.

S-001–S-004, S-007–S-008, S-010, S-013–S-020 retain their canonical sentences.
S-001–S-004, S-007, S-018–S-020 are unchanged files. S-008's explanatory additions
connect contextual comparison without treating variation as benefit. S-010 points
to S-028 for chiropractic mechanism instantiation. S-013's explanation tracks the
revised S-012 scope. S-017 changes one ordinary use of “adjustment” to “adaptation”
to prevent collision with the new chiropractic response definition.

S-006 preserves rationale beyond symptoms and its safety and missed-opportunity
boundaries while using **input** for the applied act. “Not sufficient indicators”
clarifies the old explanation's “not themselves indicators”: symptom presence alone
does not identify a functional target, without asserting that symptoms are always
empirically unrelated to neuromotor function. Symptom absence alone likewise does
not establish actionability.

S-014 retains a prospective working hypothesis; S-015 retains conditional delivery
and intentional training; S-016 retains reassessment and conditional stopping or
revision. Their explanations now distinguish outcome uncertainty from failure,
functional success from intervention worth, and response from delivery. “Training”
remains an intention unless learning or retention is separately demonstrated. No
proposition was retired, and no empirical effect was replaced with an intention.

## Counterexamples and unresolved bridges

| Case considered | Result under the revised account |
| --- | --- |
| Delivered input without reorganization | Input under S-023, no adjustment under S-024. Remains in the effectiveness accounting. |
| Input-caused reorganization without functional improvement | Adjustment, but not success under S-025. Neutral and harmful responses are possible. |
| Better range measurement with loss of needed stability | The favorable metric alone does not establish S-021's improvement. Relevant losses enter the comparison; a narrower reported gain must disclose excluded losses. |
| Local neuromotor improvement without broader transfer | Can satisfy S-025 and the scoped benefit conclusion. Does not establish S-012 or principal neural mediation under S-013. |
| Functional benefit with excessive costs or risks, or a better alternative | Can satisfy S-022 and S-027 without warranting the intervention or further input under S-014–S-016. |
| Observations unable to distinguish reorganization, causation, or improvement | Outcome remains uncertain. Success and failure are not inferred from the definition or selected retrospectively. |

Important outstanding empirical burdens remain: operational comparisons of fit
and competing functions; reliable detection of reorganization and opportunity;
causal attribution of the same improving response to the input; independently
specified salience and mechanism; prospective input selection and success frequency;
durability and generalization; broader transfer; and neural mediation and primacy.
No validated protocol or numerical threshold is invented here. A finding that
some inputs help cannot identify the right input for this person. A null result
only bears on the specified hypothesis to the extent the test could detect it.

The value criterion and professional aim are adopted evaluative commitments. They
are not undecided merely because empirical confidence is unresolved, and they do
not settle disagreements about which functional scope, demands, priorities, or
tradeoffs should guide a particular comparison. Those judgments must be explicit.
No universal benefit or requirement to pursue care is adopted.

## Proposed reading progression for Stage 4

After the S-001–S-003 method orientation, the proposed progression is:

1. Biological context: S-017, S-007, S-018, S-019, S-008, S-020.
2. Bounded functional possibilities: ARG-005 and S-004.
3. Comparative function, value, purpose, and rationale beyond symptoms: S-021,
   S-022, S-005, ARG-004, S-006.
4. Opportunities and response vocabulary: S-009, S-023, S-024, S-025.
5. What success would mean: ARG-006 and S-026, with an explicit reminder that
   this does not establish occurrence.
6. Mechanism and actual effect: S-010, S-011, S-028, ARG-007, S-027. General
   perturbation and its chiropractic instantiation carry distinct empirical burdens.
7. Separate broader questions: S-012 and S-013 as branches beyond local benefit.
8. Practice under uncertainty: ARG-002, S-014, S-015, ARG-003, S-016.

This is a proposed reading sequence only. It is neither a chain of dependencies
nor a claim that domains determine inference order. The existing domain/order
presentation is retained; only the new records receive unused orders. Stages 4
and 5 remain responsible for runtime reading paths and the integrated interface.
