## Applying the selected input

Assessment becomes action only when the working hypothesis and the person's context support proceeding. Application is that conditional practical step: the selected chiropractic input is delivered as an intentional neurobiomechanical training stimulus, with a predicted beneficial alteration of the targeted neuromotor pattern. It seeks to test the hypothesis and use the proposed opportunity for benefit.

S-014 supplies the person-specific hypothesis and selection judgment. ARG-010 uses it with S-032's practical delivery principle to support this conditional strategy. S-032 gives a reason to pursue the assessed benefit while preserving an evaluable prediction; it does not establish that proceeding is warranted. A selected input is not thereby effective, safe, or appropriate. The opportunity to test a hypothesis is insufficient by itself to justify delivery.

S-011 asserts the joint reorganization and improvement that application seeks to realize. “Training stimulus” describes the purpose of this application; it does not mean that learning, retention, or beneficial reorganization has occurred. If no available input is warranted, this step is not taken.

Application delivers the input defined in S-023. It does not deliver an already established adjustment or successful adjustment: those terms in S-024 and S-025 describe the organism's response and qualifying improvement. The input remains a delivered input whether it produces no reorganization, reorganization without improvement, harm, or an uncertain response.

## How the mechanism guides application

S-028 proposes perturbation as a mechanism of some improving responses. It informs the intended disturbance of the targeted motor-control pattern and the response predicted before delivery. This guides a hypothesis about application without establishing that the selected input will perturb that pattern or benefit this person.

If the perturbation account changes, delivery choices and predictions relying on it require reconsideration. An input may retain adequate independent justification through its effects or another explanation. That justification must actually be available; a failed mechanism cannot be replaced by an unspecified possibility. The general application strategy therefore does not require the perturbation hypothesis as a supporting premise.

## Boundary

Intention does not establish effect. Delivering an input that matches the working hypothesis does not prove that the targeted pattern was perturbed, that reorganization occurred, or that a benefit resulted. S-016 checks subsequent findings and permits stopping or revision.

v0.1 does not specify contact, direction, magnitude, rate, duration, dose, or a universal form of input. Those choices must later be made explicit and tested; neither technique selection nor a series of further inputs can be justified merely by labeling the application training.
