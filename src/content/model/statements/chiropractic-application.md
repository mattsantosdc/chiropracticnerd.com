## Applying the selected input

When assessment supports proceeding, the chiropractor applies the selected input to help change the identified neuromotor pattern. The intended change should be clear enough to check by repeating the relevant assessment afterward. This puts the working hypothesis into practice and tests the response it predicts.

**Neurobiomechanical training stimulus** describes the input's intended role: a stimulus involving mechanical interaction with the body and neural activity, used to encourage a beneficial change in control or coordination. “Training” does not mean that learning, retention, or beneficial reorganization has occurred. If no available input is warranted, this step is not taken.

The [application argument](/model/arguments/hypothesis-guided-application/) connects the assessment with the principle that a justified intervention should pursue its intended benefit and remain open to evaluation. It does not establish that proceeding is warranted in a particular case. A selected input is not thereby effective, safe, or appropriate. The opportunity to test a hypothesis is insufficient by itself to justify delivery.

The [claim that some chiropractic inputs improve neuromotor function](/model/science/chiropractic-inputs/) states the effect this application seeks to produce. The practitioner delivers the [input](/model/philosophy/chiropractic-input/); an [adjustment](/model/philosophy/adjustment/) is the person's response, and a [successful adjustment](/model/philosophy/successful-adjustment/) also requires improvement. The input remains a delivered input whether it produces no reorganization, reorganization without improvement, harm, or an uncertain response.

## How the mechanism guides application

The [perturbation account](/model/science/chiropractic-perturbation-mechanism/) proposes that some inputs help by disturbing an ongoing motor-control pattern and allowing it to reorganize. It informs the intended disturbance and the response predicted before delivery. This guides a hypothesis about application without establishing that the selected input will perturb that pattern or benefit this person.

If the perturbation account changes, delivery choices and predictions relying on it require reconsideration. An input may retain adequate independent justification through its effects or another explanation. That justification must actually be available; a failed mechanism cannot be replaced by an unspecified possibility. The general application strategy therefore does not require the perturbation hypothesis as a supporting premise.

## Boundary

Intention does not establish effect. Delivering an input that matches the working hypothesis does not prove that the targeted pattern was perturbed, that reorganization occurred, or that a benefit resulted. [Reassessment](/model/art/reassessment-cycle/) checks subsequent findings and permits stopping or revision.

v0.1 does not specify contact, direction, magnitude, rate, duration, dose, or a universal form of input. Those choices must later be made explicit and tested; neither technique selection nor a series of further inputs can be justified merely by labeling the application training.
