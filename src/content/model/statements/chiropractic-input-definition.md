## The applied stimulus

This is the Model's working definition. **Neurobiomechanical** identifies a stimulus involving mechanical interaction with the body and associated neural input or response. **Deliberately applied** distinguishes the clinical act from ordinary environmental changes. **Intended to influence** identifies its purpose without making delivery conditional on success.

The input is distinct from the organism's neuromotor reorganization, defined as an adjustment in S-024. An input can occur without an adjustment, and an adjustment can occur without improvement. The Model therefore uses **application** for delivering an input, including when the response remains unknown.

“Training stimulus” describes an intended role for the input. A single application can have that intention without establishing learning, retention, or functional improvement. This definition supplies no validated technique, dose, selection rule, or detection method. Such specifications and evidence remain necessary for testing particular input hypotheses.
